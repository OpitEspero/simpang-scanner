SIMPANGScanner pembayaran angkutan sekolah

Pindai QR siswa menggunakan kamera, atau ketik ID User secara manual.

Kamera membutuhkan izin browser dan koneksi HTTPS. Jika kamera gagal, gunakan input manual.

Setelah dilanjutkan, SIMPANG akan meminta login jika belum ada sesi aktif. Pemeriksaan siswa dan pencatatan pembayaran tetap dilakukan di aplikasi Google Apps Script.
